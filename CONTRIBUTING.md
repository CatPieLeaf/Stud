# Contributing to Stud

Here are the guidelines when you contribute to Stud:

## Generative AI usage

Adhere to [AI_USAGE_POLICY.md](AI_USAGE_POLICY.md). AI agents must NOT open and automate pull requests, a human must open them.

## Commits style

One subject line saying what changed, no body, with a prefix. For example:

```
Feature: Icons on the tray menu entries
Fixed: Broken system tray
Refactor: Stud's swapchain
```
